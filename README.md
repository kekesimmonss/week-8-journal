# week-8-journal
week 8 journal 
1. What was the problem you were solving in the projects for this course?

The main problem I addressed in this course was designing an efficient course-planning program for ABCU's Computer Science department. The program needed to load course information from a file, organize courses by course number and title, display courses in alphanumeric order, and provide information about individual courses and their prerequisites. To solve this problem, I explored different data structures, including vectors, hash tables, and binary search trees (BSTs). Each structure offered different advantages in storing, organizing, and retrieving information. My goal was to understand which data structure would best support the program's requirements while maintaining efficiency and usability.

2. How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by breaking it into smaller tasks, including loading the course data, validating the information, storing course details, sorting the course list, and searching for individual courses. I compared how vectors, hash tables, and binary search trees could accomplish these tasks and considered their time complexity using Big O notation. For example, a vector is relatively simple to implement but requires a linear search, or O(n), to find a course. A hash table provides average-case O(1) lookup time, while a balanced binary search tree can provide O(log n) search time and maintain courses in an ordered structure.

Understanding data structures is important because the way information is stored affects how efficiently a program operates. Choosing an appropriate structure can reduce processing time, improve organization, and make a program easier to maintain. Through this project, I learned that the best data structure depends on the specific needs of the application rather than simply choosing the most familiar option.

3. How did you overcome any roadblocks you encountered while going through the activities or project?

I overcame challenges by breaking the program into manageable functions and addressing problems individually. For example, reading data from a comma-separated file required careful parsing and validation to ensure that course numbers and titles were available. I also had to consider how to handle duplicate course numbers, missing prerequisites, invalid input, and attempts to search for courses that were not found. These situations helped me recognize the importance of anticipating errors instead of assuming that all input would be correct.

Another challenge was understanding the trade-offs between data structures. Although a hash table supports fast lookups, it does not automatically maintain the order required for displaying the course list. A binary search tree can produce an ordered list through an in-order traversal, but its performance depends on the tree's structure. I addressed these challenges by comparing the behavior and complexity of each option and organizing the program into separate functions for loading data, displaying courses, and retrieving course information. This process helped me develop a more systematic approach to problem-solving and debugging.

4. How has your work on this project expanded your approach to designing software and developing programs?

This project expanded my approach to software design by teaching me to consider efficiency, functionality, and maintainability before deciding how to implement a solution. Previously, I might have focused primarily on making a program produce the correct output. Now, I understand that a successful program should also use resources efficiently and accommodate future changes. Comparing vectors, hash tables, and binary search trees showed me that different structures can solve the same problem, but their performance and implementation requirements can vary significantly.

I also learned the value of separating responsibilities into functions. For example, having distinct functions for loading course information, printing the sorted course list, and displaying course prerequisites makes the program easier to understand and test. This modular approach allows changes to one part of the program without requiring unnecessary modifications to other parts. Overall, the project helped me think more critically about the relationship between program requirements, data organization, algorithm selection, and performance.

5. How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

My work on this project has encouraged me to write code that is more organized, readable, and adaptable. I learned that meaningful function names, descriptive variable names, and comments explaining important operations make code easier for other developers and me to understand. For example, separating the course-loading process from the search and display functions makes each section easier to review and troubleshoot. I also learned to validate user input and handle missing or invalid data so that the program can respond more appropriately to unexpected situations.

In addition, I now recognize the importance of designing programs so that they can accommodate future requirements. A course-planning system might eventually need additional features, such as allowing users to add courses, update prerequisites, or recommend courses based on completed requirements. Organizing the program into modular functions and using appropriate data structures provides a foundation for adding these features. This experience has taught me that maintainable software is not simply code that works today; it is code that can be understood, tested, improved, and adapted as needs change. Moving forward, I intend to apply these principles to future programming projects by prioritizing clear structure, appropriate data structures, error handling, and efficient algorithms.
